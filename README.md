# OkibaBoard（試作）

Deskboard風の「デスクトップ置き場」アプリの試作品です。
Python + Tkinter だけで作った、依存ライブラリなしの Windows 用 exe です。

## できること

- フォルダを開くと、その中にある本物のファイル／フォルダがカードになって並ぶ
- カードはドラッグで自由に動かせる
- 「＋メモ」でメモカードを追加できる（メモの文字をダブルクリックで編集）
- ファイル／フォルダのカードをダブルクリックすると、本物が開く
- カードの位置とメモは、開いたフォルダの中の `.okiba-board.json` に保存される
  （そのファイル自体はカードとして表示されません）
- 背景は濃いネイビー〜黒のダークなグラデーション風

## 使い方

1. GitHub Actions の Artifacts から `OkibaBoard.exe` をダウンロードする
2. ダブルクリックで起動する
3. 「フォルダを開く」から置き場にしたいフォルダを選ぶ

## 注意・制限（試作です）

- **本家 Deskboard の全機能版ではありません。** exe 化のルートが本物の Windows で
  通るかを確かめるための試作です。
- exe には署名がないため、初回起動時に Windows の SmartScreen 警告
  （「Windows によって PC が保護されました」）が出ることがあります。これは想定内で、
  今回の検証では解決していません。
- フォルダの中身の変更をリアルタイムで自動反映する監視機能は未実装です
  （フォルダを開き直すと最新の状態で表示されます）。
- テーマ変更、壁紙アニメーション、ウィジェットなどは未実装です。

## ビルド（GitHub Actions）

`windows-latest` 上で PyInstaller を使い、`OkibaBoard.exe` をビルドします。
ビルド後に `OkibaBoard.exe --self-test`（フォルダ走査＋保存／読み込みの
ヘッドレステスト）を実行し、`self-test-ok.txt` ができることを確認してから
exe を Artifact としてアップロードします。

ローカルでテストする場合:

```
python OkibaBoard.py --self-test
python OkibaBoard.py            # GUI 起動
```
