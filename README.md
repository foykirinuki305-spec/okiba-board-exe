# OkibaBoard v2（超シンプル版）

Deskboard風の「デスクトップ置き場」アプリです。
Deskboard の核だけに絞った、超シンプル版です。ボタンは
「フォルダを開く」と「＋メモ」の2つだけです。

## できること

- フォルダを開くと、その中にある本物のファイル／フォルダがカードになって並ぶ
- カードはドラッグで自由に動かせる（位置は自動保存）
- **エクスプローラーからファイル／フォルダを画面へドラッグ＆ドロップで追加できる**
  - 同じドライブからのドロップは「移動」、違うドライブからは「コピー」
    （エクスプローラーと同じルール）
  - 同じ名前のものがある場合は上書きしません。「名前 (2)」のように
    番号を付けて追加します
  - 追加されたカードは、ドロップした場所に現れます
- **フォルダの中身は約2秒ごとに自動で確認**：外で追加／削除したファイルも
  自動でカードに反映されます（リネームは「削除＋追加」として扱われます）
- 「＋メモ」でメモカードを追加できる（ダブルクリックで編集）
- ファイル／フォルダのカードをダブルクリックすると、本物が開く
- カードの位置とメモは、開いたフォルダの中の `.okiba-board.json` に保存される
  （そのファイル自体はカードとして表示されません）
- 背景は濃いネイビー〜黒のダークなグラデーション風

テーマ、ウィジェット、タイマー、音楽、AI などは入れていません。

## 使い方

1. GitHub Actions の Artifacts から `OkibaBoard.exe` をダウンロードする
2. ダブルクリックで起動する
3. 「フォルダを開く」から置き場にしたいフォルダを選ぶ
4. 入れたいファイルは、エクスプローラーから画面へドラッグ＆ドロップ

## 注意・制限

- **本家 Deskboard の全機能版ではありません。** 核の機能だけのシンプル版です。
- exe には署名がないため、初回起動時に Windows の SmartScreen 警告
  （「Windows によって PC が保護されました」）が出ることがあります。
- ドラッグ＆ドロップの受け付けには TkinterDnD2 を使っています。万一
  環境で読み込めない場合は、ドロップ以外の機能だけで起動します。

## ビルド（GitHub Actions）

`windows-latest` 上で PyInstaller を使い、`OkibaBoard.exe` をビルドします
（`tkinterdnd2` を `--collect-all` で同梱）。
ビルド後に `OkibaBoard.exe --self-test`（フォルダ走査＋保存／読み込み＋
ドロップ取り込みのヘッドレステスト）を実行し、`self-test-ok.txt` が
できることを確認してから exe を Artifact としてアップロードします。

ローカルでテストする場合:

```
python OkibaBoard.py --self-test
python OkibaBoard.py            # GUI 起動
```
