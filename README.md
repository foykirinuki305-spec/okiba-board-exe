# OkibaBoard v5（％サイズ・テーマ・ドラッグアウト版）

Deskboard風の「デスクトップ置き場」アプリです。
ツールの中に「ボード」を何個も作れて、それぞれがデスクトップみたいな
置き場になります。カードの置き方は本物のデスクトップと同じ
「ピチッとグリッドに吸着」する方式です。

## 仕組み

- 起動すると **ホーム画面**（暗いデスクトップ風）にボードのアイコンが並ぶ
- ボードは本物のフォルダです。場所は **ローカルディスク直下の
  `C:\OkibaBoards\`** の中（正確には `<システムドライブ>\OkibaBoards`。
  最初に自動で作られます）
  - **旧バージョンの `ドキュメント\OkibaBoards\` にボードがある場合は、
    初回起動時に自動で新しい場所へ引っ越しします。**
    引っ越しに失敗した場合は元の場所を使い続けるので、データが
    消えることはありません
  - ホーム画面の右上に、現在の保存場所（例: `保存場所: C:\OkibaBoards`）
    が小さく表示されます
  - フォルダ1つ = ボード1つ。最初は「ボード1」が1つ作られます

## ボードの名前

- **「＋ボード」を押すと必ず名前入力ダイアログが出ます。**
  好きな名前を自由に決めてください（最初から入っている「ボードN」は
  下書きなので、そのまま書き換えてOKです）
  - 名前はそのまま **実際のフォルダ名** になります
  - 空欄のまま／キャンセルした場合は、ボードは作られません
  - フォルダ名に使えない文字（`\ / : * ? " < > |`）が入っていると、
    **勝手に書き換えずに**「使えない文字が含まれています」と表示して
    作りません。文字を直してやり直してください
- 作ったあとも、ホームでボードを **右クリック →「名前変更」** で
  いつでも変えられます（実際のフォルダ名も変わります）。
  右クリックには「場所を開く」「ゴミ箱へ削除」もあります

## 置き方（グリッド方式）

ホームのアイコンも、ボードの中のカードも、置き方は同じです。

- **ドラッグで好きなマスへ移動**：カードのどこを掴んでもドラッグでき、
  カードはカーソルについてきます。離すと一番近いマスにピチッと
  吸着し、その場で保存されます
- **縦の列から埋まる**：新しいものは、デスクトップのアイコンと同じく
  左の列を上から下へ埋めて、次に右隣の列、という順番で並びます
- **場所の交換**：すでに物があるマスに置くと、2つが場所を
  入れ替えます（スワップ）。メモカードとも入れ替わります
- 位置はマス単位で保存され、次に開いたときも同じ並びで復元されます

## 大きさ（％指定）

- ボード画面の **「大きさ: 80%」ボタン** を押すたびに
  **25 → 30 → 40 → 50 → 60 → 70 → 80 → 90 → 100 → 125 → 25…**
  と切り替わります（100% がこれまでの「中」の大きさです）。
  小さい側が細かく選べるので、「もうちょっと小さく」がしやすいです
- カードの大きさ・マスの大きさ・文字の大きさが一緒に変わります。
  並び（マス）は変わりません
- 選んだ％はボードごとに `.okiba-board.json` へ保存されます
  （旧バージョンの「小／中／大」は、小=70%／中=100%／大=125% として
  読み込まれます）

## テーマ（見た目）

- ホーム画面とボード画面の両方にある **「テーマ: 紺」ボタン** を
  押すたびに、テーマが順番に切り替わります。全て **明るすぎない
  ダーク系** です
  - **紺**：濃紺〜黒（今までの色）
  - **黒グレー**：ほぼ黒〜ダークグレー
  - **深緑**：深いグリーン
  - **紫夜**：紫がかった夜色
  - **焦げ茶**：焦げ茶〜ワイン系
- テーマで、背景のグラデーション・ツールバー・ボタン・カードの
  影と枠のアクセント色が一式で変わります
- 選んだテーマはアプリ全体（ホーム＋全ボード共通）で1つだけ保存され、
  次に開いたときも同じテーマで始まります（ボードごとの個別テーマは
  ありません）

## カードの見た目

- カードは **角丸＋柔らかい影** つき。枠は細く控えめで、
  マウスを乗せると枠が少し明るくなります
- **種類ごとに色分け** されているので、ひと目で分かります
  - フォルダ＝黄色系 📁／動画＝紫系 🎬／画像＝緑系 🖼／
    音声＝ピンク系 🎵／メモ＝暖色 📝／その他＝青系 📄
    （その他ファイルの枠色はテーマのアクセント色になります）
- **画像ファイル（jpg/png等）はサムネイル表示** になります
  （Pillow を使用。読み込めない画像は通常のアイコン表示になります）

## ボード画面でできること

ボタンは **「← もどる」「＋メモ」「＋ファイル」「大きさ」「テーマ」**
だけです。

- フォルダの中にある本物のファイル／フォルダがカードになって並ぶ
- **ファイルの入れ方は2通り**
  1. エクスプローラーから画面へ **ドラッグ＆ドロップ**
     （Windows 標準の仕組み＝WM_DROPFILES を使っています）
  2. **「＋ファイル」ボタン**で選ぶ（こちらは確実に動きます）
  - どちらも、同じドライブからは「移動」、違うドライブからは「コピー」
    （エクスプローラーと同じルール）
  - 同じ名前のものがある場合は上書きしません。「名前 (2)」のように
    番号を付けて追加します
  - 落とした場所のマスから、縦の列順に並びます
  - 画面上のヒントに「ファイルをここに落とせます」と出ていれば
    ドロップ受け付け中です。出ていない場合は「＋ファイル」を使ってください
- **ボードの外への移動も反映されます**
  - エクスプローラー等でボードのフォルダからファイルを出し入れすると、
    カードが消えたり現れたりします（約2秒ごとの自動確認＋
    ウィンドウに戻ったときの即時再確認）
  - **ドラッグアウト**：カードをドラッグしたまま画面の外へ持っていくと、
    Windows 標準のドラッグ（OLE）としてデスクトップやエクスプローラーへ
    落とせます。移動で落とすとカードは消えます
    （環境によって効かない場合があるため、次の方法が確実です）
  - **右クリック →「デスクトップへ移動」**：素材を実デスクトップへ
    移動します。カードは消えます（ドラッグアウトの保険として常に使えます）
- カードを **右クリック**：「開く」／**「場所を開く」**／
  **「デスクトップへ移動」**／「名前変更」（本物のファイル名も変わります）／
  「ゴミ箱へ削除」（Windows のゴミ箱へ。戻せます）
  - **「場所を開く」**：ファイルなら、そのファイルを選んだ状態で
    エクスプローラーが開きます。フォルダのカードなら、そのフォルダ
    自体がエクスプローラーで開きます。「PCのどこにあるか」が
    いつでも確認できます
- カードをダブルクリックすると、本物のファイルが開く
- 「＋メモ」でメモカードを追加できる（ダブルクリック／右クリックで編集、
  右クリックで削除）。メモもカードと同じマスに吸着します
- カードの位置（マス）とメモと大きさ（％）は、そのボードのフォルダの中の
  `.okiba-board.json` に保存されます（そのファイル自体はカードとして
  表示されません）

## 使い方

1. GitHub Actions の Artifacts から `OkibaBoard.exe` をダウンロードする
2. ダブルクリックで起動する（ホーム画面が出ます）
3. 「＋ボード」で名前を決めてボードを作る
4. ボードのアイコンをダブルクリックで開く
5. 入れたいファイルは、ドラッグ＆ドロップか「＋ファイル」ボタンで

## 注意・制限

- **本家 Deskboard の全機能版ではありません。** 核の機能だけのシンプル版です。
- exe には署名がないため、初回起動時に Windows の SmartScreen 警告
  （「Windows によって PC が保護されました」）が出ることがあります。
- ドラッグ＆ドロップ（入れる方・出す方とも）は Windows 標準の仕組みで
  実装していますが、「実際に画面上でドラッグする操作」自体は自動テストが
  できません。入れられない場合は「＋ファイル」、出せない場合は
  右クリック「デスクトップへ移動」を使ってください。
- 見た目（テーマ・影・サムネイル等）も、ヘッドレスの自動テストでは
  スクリーンショット確認ができません。実機での見え方を確認してください。
- グリッドの列の高さは画面の高さで決まります。画面を小さくして
  列に入りきらない位置のカードは、見えている範囲の外に出ることが
  あります（データは消えません。画面を広げれば見えます）。

## ビルド（GitHub Actions）

`windows-latest` 上で PyInstaller を使い、`OkibaBoard.exe` をビルドします
（実行時の必須依存は Python 標準ライブラリのみ。画像サムネイル用の
Pillow を同梱しますが、無くてもアイコン表示で動作します）。
ビルド後に `OkibaBoard.exe --self-test`（保存場所の解決と引っ越し、
グリッド計算＝吸着・縦列の並び順・スワップ、ドラッグのデータ流れ、
％サイズの保存／復元と旧サイズ移行、テーマ定義の妥当性と保存／復元、
ボード作成／名前変更（使えない文字の拒否を含む）、ホーム配置の保存／
読み込み、フォルダ走査、ボード保存／読み込み、取り込み・排出ヘルパー、
ドラッグアウト用 HDROP データのヘッドレステスト）を実行し、
`self-test-ok.txt` ができることを確認してから exe を Artifact として
アップロードします。self-test は `OKIBA_BASE` 環境変数で保存場所を
一時フォルダに切り替えるため、CI の実ドライブやドキュメントには
触りません。

ローカルでテストする場合:

```
python OkibaBoard.py --self-test
python OkibaBoard.py            # GUI 起動
```
