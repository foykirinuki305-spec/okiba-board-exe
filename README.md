# OkibaBoard v3（複数ボード・超シンプル版）

Deskboard風の「デスクトップ置き場」アプリです。
ツールの中に「ボード」を何個も作れて、それぞれがデスクトップみたいな
置き場になります。ボタンは最小限だけ、という超シンプル版です。

## 仕組み

- 起動すると **ホーム画面**（暗いデスクトップ風）にボードのアイコンが並ぶ
- ボードは本物のフォルダです。場所は
  **`ドキュメント\OkibaBoards\`** の中（最初に自動で作られます）
  - フォルダ1つ = ボード1つ。最初は「ボード1」が1つ作られます
  - ボードを増やすのはホームの **「＋ボード」ボタンだけ**
  - アイコンをダブルクリックで、そのボードが開きます
  - アイコンを右クリックで「名前変更」（本物のフォルダ名も変わります）／
    「ゴミ箱へ削除」（フォルダごと Windows のゴミ箱へ。戻せます）
  - **アイコンはグリッドやスナップなしで、完全に自由な位置に置けます**
    （本物のデスクトップと同じ）。置いた場所はそのまま保存・復元されます

## ボード画面でできること

ボタンは **「← もどる」「＋メモ」「＋ファイル」** の3つだけです。

- フォルダの中にある本物のファイル／フォルダがカードになって並ぶ
- **カードは完全に自由な位置に置けます。整列やスナップは一切しません。**
  自分で置いた位置が自動で直されることはありません
  （外の変更を取り込む再描画のときも、保存済みの位置をそのまま復元します）
- **ファイルの入れ方は2通り**
  1. エクスプローラーから画面へ **ドラッグ＆ドロップ**
     （Windows 標準の仕組み＝WM_DROPFILES を使っています）
  2. **「＋ファイル」ボタン**で選ぶ（こちらは確実に動きます）
  - どちらも、同じドライブからは「移動」、違うドライブからは「コピー」
    （エクスプローラーと同じルール）
  - 同じ名前のものがある場合は上書きしません。「名前 (2)」のように
    番号を付けて追加します
  - 画面上のヒントに「ファイルをここに落とせます」と出ていれば
    ドロップ受け付け中です。出ていない場合は「＋ファイル」を使ってください
- カードを **右クリック**：「開く」／「名前変更」（本物のファイル名も
  変わります）／「ゴミ箱へ削除」（Windows のゴミ箱へ。戻せます）
- カードをダブルクリックすると、本物のファイルが開く
- 「＋メモ」でメモカードを追加できる（ダブルクリックで編集、
  右クリックで編集／削除）
- **フォルダの中身は約2秒ごとに自動で確認**：外で追加／削除したファイルも
  自動でカードに反映されます（リネームは「削除＋追加」として扱われます）
- カードの位置とメモは、そのボードのフォルダの中の `.okiba-board.json`
  に保存されます（そのファイル自体はカードとして表示されません）
- 背景は濃いネイビー〜黒のダークなグラデーション風

テーマ、ウィジェット、タイマー、音楽、AI などは入れていません。

## 使い方

1. GitHub Actions の Artifacts から `OkibaBoard.exe` をダウンロードする
2. ダブルクリックで起動する（ホーム画面が出ます）
3. ボードのアイコンをダブルクリックで開く
4. 入れたいファイルは、ドラッグ＆ドロップか「＋ファイル」ボタンで

## 注意・制限

- **本家 Deskboard の全機能版ではありません。** 核の機能だけのシンプル版です。
- exe には署名がないため、初回起動時に Windows の SmartScreen 警告
  （「Windows によって PC が保護されました」）が出ることがあります。
- ドラッグ＆ドロップは Windows 標準の仕組みで実装していますが、
  「実際に画面上でドラッグして落とす操作」自体は自動テストができません。
  万一ドロップが効かない環境でも、「＋ファイル」ボタンからは
  同じ取り込みができます。

## ビルド（GitHub Actions）

`windows-latest` 上で PyInstaller を使い、`OkibaBoard.exe` をビルドします
（依存は Python 標準ライブラリのみ）。
ビルド後に `OkibaBoard.exe --self-test`（ボード作成／一覧／名前変更、
ホーム配置の保存／読み込み、フォルダ走査、ボード保存／読み込み、
取り込みヘルパーのヘッドレステスト）を実行し、`self-test-ok.txt` が
できることを確認してから exe を Artifact としてアップロードします。

ローカルでテストする場合:

```
python OkibaBoard.py --self-test
python OkibaBoard.py            # GUI 起動
```
